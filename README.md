# Invitación Toy Story — Ross Digital Studio

Versión modernizada del modelo temático Toy Story.

La estructura está pensada para personalizar rápidamente nombre, edad, fecha, horario, lugar, Google Maps, WhatsApp e Instagram desde `js/config.js`.

Incluye música, personajes rotativos, contador regresivo, ubicación, confirmación por WhatsApp, animaciones y diseño responsive.

Diseñado por Ross Digital Studio.
